# ReffMC Ultimate Roleplay

Minecraft Java 1.20.1 Forge 47.4.29 starter mod.

This repository is built automatically by GitHub Actions. Open the Actions tab and download the `reffmcultimate-jar` artifact after the build succeeds.

Current starter features: Bozo, Sus Villager, Officer Max and Roleplay Villager NPCs, spawn eggs, basic wandering/look-at-player behavior, dialogue interactions and `/reffmc` commands.

This is an early starter release, not the full planned roleplay feature set.
